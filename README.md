# TNT Crane Homepage

Responsive homepage redesign for TNT Crane & Rigging focused on improved user experience, navigation, and lead generation.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
